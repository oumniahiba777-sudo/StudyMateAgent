# StudyMate — LangGraph Educational Agent

A simple educational AI agent built with LangGraph, LangChain, Gemini 2.5 Flash, and Streamlit.

## Features
- Gemini-powered agent
- LangGraph state and conditional routing
- Tool calling
- Course information tool
- Study-plan tool
- Interactive web UI

## Deployment
Deploy `app.py` on Streamlit Community Cloud and add `GEMINI_API_KEY` under App Settings → Secrets.
